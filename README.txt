This folder is for the results of the College Canteen Sales Analyzer.

When you run  Rscript run_project.R  the program creates these files here:

  analysis_report.txt   - full text report
  item_sales.png        - Sales by Item
  category_sales.png    - Sales by Category
  time_sales.png        - Sales by Time
  revenue_by_item.png   - Revenue by Item

Running the project again will overwrite these files with new results.
